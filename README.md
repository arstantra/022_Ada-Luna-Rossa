ADA Luna Rossa è un'applicazione web React costruita con Vite e TypeScript per la gestione avanzata di progetti architettonici e di pianificazione. Integra l'API Google Generative (Gemini) per analisi intelligente, parsing di documenti di progettazione e supporto alla documentazione in tempo reale.

Il progetto è organizzato con una struttura modulare comprendente servizi di backend (parsing, database, API Gemini), componenti React specializzati per diverse modalità di lavoro, hooks personalizzati per la gestione dello stato, e una configurazione build ottimizzata tramite Vite. Include file di documentazione interna (CLAUDE.md, CLAUDE_PROTOCOL.md) per la continuità del lavoro con assistenti AI.
